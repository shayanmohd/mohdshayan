Questions

                        
Built by Mohd Shayan. Found a problem or have an idea? Send a note.

                    

                    

                        

                            Do these QR codes expire?
                            
No. They are static codes: the link, Wi-Fi details or payment information are stored inside the pattern itself. Many free generators create dynamic codes that point at their own redirect server and stop working when a trial ends. These cannot, because there is no server involved.

                        

                        

                            How do I make a UPI payment QR code?
                            
Choose UPI, enter the UPI ID that should receive the money (for example name@bank) and the payee name. Add an amount to fix it, or leave it empty so the payer types one. Any UPI app, such as Google Pay, PhonePe, Paytm or BHIM, can scan it. Scan it yourself with a small test payment before you print it.

                        

                        

                            Which error correction level should I choose?
                            
Higher levels let a code survive smudges, folds and logos placed on top, at the cost of a denser pattern. Medium suits most uses. Choose Quartile or High for printed codes that might be damaged, and Low to keep a long payload scannable at a small size.

                        

                        

                            How big should a printed QR code be?
                            
A common rule is a width of at least a tenth of the scanning distance, and never under about 2 cm. Keep the quiet margin around the code, keep strong contrast, and use dark modules on a light background: many scanners cannot read inverted codes.

                        

                        

                            Is my Wi-Fi password safe?
                            
The code is made on your device and nothing is uploaded. Remember that anyone who can scan the finished code can read the password inside it, so treat a printed Wi-Fi code like the password itself.
