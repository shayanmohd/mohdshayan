What each button does

The formatter works on the text itself rather than through JSON.parse, so a number written as 1.0 stays 1.0, escapes stay escapes, and keys move only when you ask.

Format

Rewrites the whitespace between values with your indent, one value per line, and changes nothing else.

{"a":[1,2]} → {
  "a": [
    1,
    2
  ]
}

Minify

Removes every space, tab and line break outside strings: the smallest text that still parses to the same value.

{ "a": [ 1, 2 ] } → {"a":[1,2]}

Sort keys

Orders the keys of every object by character code, at every depth, then formats. Arrays keep their order.

{"b":1,"a":{"d":1,"c":2}} → {
  "a": {
    "c": 2,
    "d": 1
  },
  "b": 1
}

Validate

Checks the whole document and reports the first problem with its line, its column and an excerpt of that line.

[1, 2,] → Line 1, column 6. Trailing comma
